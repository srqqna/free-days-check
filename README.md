# เพื่อนว่างวันไหน

หาวันที่เพื่อนว่างตรงกัน ไม่ต้องสมัคร ไม่ต้องล็อกอิน แค่เปิดลิงก์แล้วแตะวัน

**เปิดเว็บ:** https://srqqna.github.io/free-days-check/

---

## สำหรับเพื่อนที่ได้ลิงก์มา

1. เปิดลิงก์นัดที่เพื่อนส่งมา
2. ใส่ **ชื่อเรา** (และ **หมายเหตุ** ถ้ามี เช่น "ว่างหลัง 6 โมงเย็น")
3. แตะวันในปฏิทิน
   - แตะ 1 ครั้ง = **ว่าง**
   - แตะ 2 ครั้ง = **อาจจะว่าง**
   - แตะ 3 ครั้ง = เอาออก
4. วันที่ว่าง เลือกช่วงเวลาได้ใต้ปฏิทิน: ทั้งวัน / เช้า / บ่าย / เย็น
5. ระบบบันทึกให้อัตโนมัติ ทุกคนเห็นทันที

### เลือกหลายวันเร็วๆ

- **เสาร์–อาทิตย์เดือนนี้** เลือกทุกเสาร์-อาทิตย์ (กดอีกครั้งเพื่อเอาออก)
- กดชื่อวัน **อา จ อ พ พฤ ศ ส** เลือกวันนั้นทั้งเดือน
- **เลือกเป็นช่วง** แตะวันแรก แล้วแตะวันสุดท้าย
- คอมพิวเตอร์: กดค้างแล้วลากเมาส์
- **ล้างเดือนนี้** เอาวันของเราในเดือนนี้ออกทั้งหมด

### อ่านปฏิทินยังไง

| เห็นแบบนี้ | แปลว่า |
|---|---|
| ช่องสีครีม → น้ำตาลดินเผา | ยิ่งเข้ม ยิ่งมีคนว่างวันนั้นเยอะ |
| ตัวเลขเล็กในช่อง เช่น `3 คน` | จำนวนคนที่ว่างวันนั้น |
| กรอบเข้ม + จุดมุมขวา | วันที่เราเลือกว่าง |
| กรอบส้มลายเฉียง + `?` | วันที่เราอาจจะว่าง |
| `+1?` สีส้มในช่อง | มีคนอาจจะว่างเพิ่ม |
| ตัวเลขแดง + จุดแดงล่าง | วันหยุดราชการ (ชื่อวันหยุดอยู่ใต้ปฏิทิน) |
| ช่องจางกดไม่ได้ | อยู่นอกช่วงที่แอดมินกำหนด |
| กรอบเขียว + ✓ | วันที่แอดมินยืนยันนัดแล้ว |
| ตัวเลขขีดเส้นใต้ | วันนี้ |

ใต้ปฏิทินมี **วันที่ว่างตรงกันมากสุด** และ **ใครลงแล้วบ้าง** (จุดเขียวข้างชื่อ = เปิดหน้านี้อยู่ตอนนี้)
ด้านบนบอก **ออนไลน์กี่คน** ข้อมูลอัปเดตสด ช่องที่เพื่อนเพิ่งแก้จะกะพริบ

### อยากแก้วันที่ลงไว้

เปิดลิงก์เดิมในเครื่องเดิม แตะวันใหม่ได้เลย

### ใช้หลายเครื่อง

1. เครื่องแรก: กด **ใช้หลายเครื่อง / ลบชื่อฉัน** > ตั้ง **PIN**
2. เครื่องใหม่: เปิดลิงก์เดิม > **ใช้หลายเครื่อง** > เลือกชื่อ > ใส่ PIN > **ใช้ชื่อนี้**

ไม่ได้ตั้ง PIN ไว้: ลงใหม่ แล้วบอกแอดมินให้ลบชื่อเก่า

### ถอนตัว

**ใช้หลายเครื่อง / ลบชื่อฉัน** > **ลบชื่อฉันออกจากนัดนี้** (กด 2 ครั้ง)

### ชวนเพื่อนต่อ

ปุ่ม **คัดลอกลิงก์**, **ส่งใน LINE** หรือ **QR** ให้เพื่อนสแกน

### ปิดรับแล้ว

ถ้าเลยวันปิดรับที่แอดมินตั้งไว้ จะแก้วันไม่ได้ (แอดมินยังแก้ได้)

## สำหรับคนสร้างนัด

### สร้างนัด

1. เปิด https://srqqna.github.io/free-days-check/
2. ใส่ **ชื่อนัด** เช่น `ทริปเชียงใหม่` (ภาษาไทยได้)
3. ตั้ง **รหัสแอดมิน** อย่างน้อย 4 ตัว (แนะนำ 6 ตัวขึ้นไป) **จดไว้ เปลี่ยนทีหลังไม่ได้**
4. กด **สร้างลิงก์** แล้วกด **คัดลอกลิงก์** หรือ **ส่งใน LINE**

ถ้าขึ้นว่า "ชื่อนัดนี้มีคนสร้างไว้แล้ว" ให้ใช้ชื่ออื่น

### เป็นแอดมินบนเครื่องไหนก็ได้

1. เปิดลิงก์นัด เลื่อนลงล่างสุด กด **แอดมินนัดนี้**
2. ใส่รหัสแอดมิน กด **เข้าโหมดแอดมิน**

ส่งรหัสให้เพื่อนที่ไว้ใจ เพื่อนก็เป็นแอดมินได้

### แก้รายละเอียดนัด (แอดมิน)

ในกล่อง **แอดมินนัดนี้** กด **แก้รายละเอียดนัด**

- ชื่อนัด สถานที่ เวลา คำอธิบาย
- **ให้เลือกได้ตั้งแต่ / ถึง** จำกัดช่วงวัน ปฏิทินจะเปิดที่เดือนนั้น
- **ปิดรับวันที่** หลังวันนี้เพื่อนแก้ไม่ได้
- **รายชื่อคนที่ควรมา** เว็บจะบอกว่าใคร **ยังไม่ได้ลง**
- **ลบนัดนี้ทั้งนัด** (กด 2 ครั้ง ลบถาวร)

### ยืนยันวันนัด (แอดมิน)

1. ในกล่อง **ยืนยันวัน** กด **เลือกวันที่จะนัด**
2. แตะวันในปฏิทิน หรือพิมพ์ แล้วกด **ใส่**
   - ช่วงวัน: `10-13`
   - หลายวัน: `10,12,15`
   - ใช้วันของเดือนที่ปฏิทินแสดงอยู่
3. ดูสรุป
   - **มาได้ทุกวัน** — ใครบ้าง กี่คน
   - **ว่างบางวัน** — ใคร และไม่ว่างวันไหน
   - **ไม่ว่างเลย** — ใครบ้าง
4. กด **ยืนยันวันนี้** ทุกคนจะเห็นแถบสีเขียวด้านบนพร้อมวันที่นัด

หลังยืนยัน ทุกคนกด **เพิ่มลง Google Calendar** หรือ **ดาวน์โหลด .ics** (iPhone / Outlook) ได้จากแถบสีเขียว

เปลี่ยนใจ: กด **ยกเลิกการยืนยัน** (กด 2 ครั้ง)

### ลบชื่อคนที่ลง (แอดมิน)

ในรายการ **ใครลงแล้วบ้าง** กด **ลบ** ข้างชื่อ แล้วกด **ยืนยันลบ**

## คำถามที่พบบ่อย

**ต้องสมัครอะไรไหม**
ไม่ต้อง เปิดลิงก์แล้วใช้ได้เลย

**คนอื่นแก้วันของเราได้ไหม**
ไม่ได้ แต่ละคนแก้ได้เฉพาะของตัวเอง แอดมินลบชื่อได้อย่างเดียว

**ลืมรหัสแอดมิน**
กู้ไม่ได้ ให้สร้างนัดใหม่ หรือถามเพื่อนที่มีรหัส

**ลิงก์ภาษาไทยยาวมาก**
ใช้ได้ปกติ ถ้าอยากได้ลิงก์สั้น ตั้งชื่อนัดเป็นภาษาอังกฤษ เช่น `cnx-trip`

**เว็บไม่อัปเดต / หน้าตาแปลก**
กด Ctrl+F5 (คอม) หรือปิดแล้วเปิดแท็บใหม่ (มือถือ)
