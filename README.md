# ว่างวันไหน

เว็บเล็กๆ ไว้หาวันที่แก๊งเราว่างตรงกัน ส่งลิงก์เข้ากลุ่ม ให้ทุกคนจิ้มวันที่ว่าง แล้วดูว่าวันไหนคนว่างเยอะสุด

เปิดเว็บ: https://srqqna.github.io/free-days-check/

---

## ได้ลิงก์จากเพื่อนมา ทำยังไง

1. เปิดลิงก์
2. ใส่ชื่อตัวเอง จะใส่หมายเหตุด้วยก็ได้ เช่น "ว่างหลัง 6 โมงเย็น"
3. จิ้มวันในปฏิทิน
   - จิ้มครั้งแรก = ว่าง
   - จิ้มอีกที = อาจจะว่าง
   - จิ้มครั้งที่สาม = เอาออก
4. ถ้าว่างแค่บางช่วง เลือกได้ใต้ปฏิทินว่า เช้า บ่าย หรือเย็น

แค่นั้นเลย เว็บบันทึกให้เอง เพื่อนเห็นทันที

### ขี้เกียจจิ้มทีละวัน

- กด **เสาร์–อาทิตย์เดือนนี้** ได้ทุกเสาร์อาทิตย์ในทีเดียว กดอีกทีเอาออก
- กดชื่อวันด้านบน (อา จ อ พ พฤ ศ ส) เลือกวันนั้นทั้งเดือน
- กด **เลือกเป็นช่วง** แล้วจิ้มวันแรกกับวันสุดท้าย
- ในคอม กดค้างแล้วลากเมาส์ได้เลย
- เลือกผิดเยอะ กด **ล้างเดือนนี้**

### ดูปฏิทินยังไง

| เห็นแบบนี้ | หมายความว่า |
|---|---|
| สีเข้มขึ้นเรื่อยๆ | ยิ่งเข้ม ยิ่งมีคนว่างวันนั้นเยอะ |
| `3 คน` ในช่อง | วันนั้นมีคนว่าง 3 คน |
| `+1?` สีส้ม | มีอีก 1 คนที่อาจจะว่าง |
| กรอบเข้มกับจุดที่มุม | วันที่เราว่าง |
| กรอบส้มลายเฉียงกับ `?` | วันที่เราอาจจะว่าง |
| กรอบเขียวกับ ✓ | วันที่นัดกันแล้ว |
| ตัวเลขสีแดง | วันหยุดราชการ ชื่อวันหยุดอยู่ใต้ปฏิทิน |
| ช่องจางๆ กดไม่ได้ | อยู่นอกช่วงวันที่คนสร้างนัดกำหนดไว้ |

ข้างๆ (หรือใต้ปฏิทินในมือถือ) มีสรุปว่า **วันไหนว่างตรงกันมากสุด** และ **ใครลงแล้วบ้าง** จุดเขียวข้างชื่อแปลว่าคนนั้นเปิดหน้านี้อยู่ตอนนี้ ถ้าเพื่อนเพิ่งแก้วันไหน ช่องนั้นจะกะพริบให้เห็น

### อยากแก้วันที่ลงไว้

เปิดลิงก์เดิมในเครื่องเดิม แล้วจิ้มใหม่ได้เลย

### เปลี่ยนเครื่อง

เว็บจำเราจากเครื่องที่ใช้ ถ้าจะไปแก้จากอีกเครื่อง ให้ตั้ง PIN ไว้ก่อน

1. เครื่องเดิม: กด **ใช้หลายเครื่อง / ลบชื่อฉัน** แล้วตั้ง PIN
2. เครื่องใหม่: เปิดลิงก์เดิม กด **ใช้หลายเครื่อง** เลือกชื่อตัวเอง ใส่ PIN แล้วกด **ใช้ชื่อนี้**

ลืมตั้ง PIN ก็ไม่เป็นไร ลงใหม่ได้เลย แล้วบอกแอดมินให้ลบชื่อเก่าให้

### ไม่ไปแล้ว

กด **ใช้หลายเครื่อง / ลบชื่อฉัน** แล้วกด **ลบชื่อฉันออกจากนัดนี้** สองครั้ง

### ชวนคนอื่นมาด้วย

กด **คัดลอกลิงก์** หรือ **ส่งใน LINE** หรือกด **QR** ให้เพื่อนสแกนจากจอเรา

### ทำไมแก้ไม่ได้แล้ว

คนสร้างนัดอาจตั้งวันปิดรับไว้ เลยวันนั้นแล้วจะแก้ไม่ได้ ถ้าจำเป็นจริงๆ ทักแอดมินให้แก้ให้

## อยากสร้างนัดเอง

### สร้างนัด

1. เปิด https://srqqna.github.io/free-days-check/
2. ตั้งชื่อนัด เช่น `ทริปเชียงใหม่` ภาษาไทยได้
3. ตั้งรหัสแอดมิน อย่างน้อย 4 ตัว (6 ตัวขึ้นไปจะดีกว่า) **จดไว้ด้วย** ต้องใช้ตอนยืนยันวัน
4. กด **สร้างลิงก์** แล้วส่งเข้ากลุ่ม

ถ้าขึ้นว่า "ชื่อนี้มีคนใช้แล้ว" ลองเปลี่ยนชื่อนิดหน่อย เช่น ใส่เดือนต่อท้าย

นัดที่เราสร้างหรือเคยเปิดจะอยู่ใน **นัดของฉัน** ใต้ฟอร์ม กลับมาเปิดได้ง่ายๆ

### เป็นแอดมินจากเครื่องอื่น

เปิดลิงก์นัด กล่อง **แอดมินนัดนี้** อยู่ด้านบน ใส่รหัสแอดมินแล้วกด **เข้าโหมดแอดมิน**

จะให้เพื่อนช่วยดูแลนัดด้วย ก็ส่งรหัสให้เพื่อนคนนั้นได้เลย

### แก้รายละเอียดนัด

ในกล่อง **แอดมินนัดนี้** กด **แก้รายละเอียดนัด** แก้ได้ทั้ง

- ชื่อนัด สถานที่ เวลา และคำอธิบาย
- ช่วงวันที่ให้เลือก เช่น ให้เลือกได้แค่ธันวาคม
- วันปิดรับ เลยวันนี้แล้วเพื่อนจะแก้วันไม่ได้
- รายชื่อคนที่ควรมา เว็บจะบอกว่าใครยังไม่ได้ลง จะได้ไปตามถูกคน

ปุ่ม **ลบนัดนี้ทั้งนัด** ก็อยู่ตรงนี้ ลบแล้วกู้คืนไม่ได้นะ

### เลือกวันนัด

1. ในกล่อง **แอดมินนัดนี้** กด **ไปหน้ายืนยันวัน**
2. จิ้มวันที่จะนัดในปฏิทิน จิ้มซ้ำเพื่อเอาออก
3. ดูสรุปว่าใครมาได้ทุกวัน ใครว่างแค่บางวัน ใครไม่ว่างเลย
4. โอเคแล้วกด **ยืนยันวันนี้**

พอยืนยันแล้ว ทุกคนจะเห็นแถบสีเขียวบอกวันนัด กดได้ทั้ง

- **ส่งสรุปเข้า LINE** ส่งข้อความสรุปเข้ากลุ่ม เพื่อนไม่ต้องเปิดเว็บก็รู้ว่านัดวันไหน ใครมาบ้าง
- **เพิ่มลง Google Calendar** หรือ **ดาวน์โหลด .ics** สำหรับปฏิทินใน iPhone หรือ Outlook

เปลี่ยนใจทีหลังก็กด **เปลี่ยนวันนัด** หรือ **ยกเลิกการยืนยัน** ได้

### ลบชื่อคนที่ลง

ในรายการ **ใครลงแล้วบ้าง** กด **ลบ** ข้างชื่อ แล้วกด **ยืนยันลบ** อีกที

## สงสัยไหม

**ต้องสมัครหรือล็อกอินไหม**
ไม่ต้อง เปิดลิงก์แล้วใช้ได้เลย

**คนอื่นมาแก้วันของเราได้ไหม**
ไม่ได้ แต่ละคนแก้ได้แค่ของตัวเอง แอดมินทำได้แค่ลบชื่อ

**ลืมรหัสแอดมิน**
ทักเจ้าของเว็บ ดูรหัสหรือตั้งรหัสใหม่ให้ได้

**ลิงก์ภาษาไทยยาวเหยียด**
ส่งไปก็ใช้ได้ปกติ แต่ถ้าอยากได้ลิงก์สั้นๆ ตั้งชื่อนัดเป็นภาษาอังกฤษ เช่น `cnx-trip`

**หน้าเว็บดูแปลกๆ หรือไม่อัปเดต**
ในคอมกด Ctrl+F5 ในมือถือปิดแท็บแล้วเปิดใหม่
