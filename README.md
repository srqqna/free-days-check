# เพื่อนว่างวันไหน

หาวันที่เพื่อนว่างตรงกัน ไม่ต้องสมัคร ไม่ต้องล็อกอิน แค่เปิดลิงก์แล้วแตะวัน

**เปิดเว็บ:** https://srqqna.github.io/free-days-check/

---

## สำหรับเพื่อนที่ได้ลิงก์มา

1. เปิดลิงก์นัดที่เพื่อนส่งมา
2. ใส่ **ชื่อเรา**
3. แตะวันที่ว่างในปฏิทิน แตะซ้ำเพื่อเอาออก
4. ระบบบันทึกให้อัตโนมัติ คนอื่นเห็นทันที

### อ่านปฏิทินยังไง

| เห็นแบบนี้ | แปลว่า |
|---|---|
| ช่องสีฟ้าอ่อน → น้ำเงินเข้ม | ยิ่งเข้ม ยิ่งมีคนว่างวันนั้นเยอะ |
| ตัวเลขเล็กในช่อง เช่น `3 คน` | จำนวนคนที่ว่างวันนั้น |
| กรอบน้ำเงิน + จุดมุมขวา | วันที่เราเลือกว่าง |
| กรอบเขียว + ✓ | วันที่แอดมินยืนยันนัดแล้ว |
| ตัวเลขน้ำเงินขีดเส้นใต้ | วันนี้ |

ใต้ปฏิทินมี **วันที่ว่างตรงกันมากสุด** และ **ใครลงแล้วบ้าง**

### อยากแก้วันที่ลงไว้

เปิดลิงก์เดิมในเครื่องและเบราว์เซอร์เดิม แตะวันใหม่ได้เลย

> ถ้าเปลี่ยนเครื่อง หรือล้างข้อมูลเบราว์เซอร์ ระบบจะนับเป็นคนใหม่ ให้ลงใหม่ แล้วบอกแอดมินให้ลบชื่อเก่า

---

## สำหรับคนสร้างนัด

### สร้างนัด

1. เปิด https://srqqna.github.io/free-days-check/
2. ใส่ **ชื่อนัด** เช่น `ทริปเชียงใหม่` (ภาษาไทยได้)
3. ตั้ง **รหัสแอดมิน** อย่างน้อย 4 ตัว (แนะนำ 6 ตัวขึ้นไป) **จดไว้ เปลี่ยนทีหลังไม่ได้**
4. กด **สร้างลิงก์** แล้วกด **คัดลอกลิงก์** ส่งให้เพื่อน

ถ้าขึ้นว่า "ชื่อนัดนี้มีคนสร้างไว้แล้ว" ให้ใช้ชื่ออื่น

### เป็นแอดมินบนเครื่องไหนก็ได้

1. เปิดลิงก์นัด เลื่อนลงล่างสุด กด **แอดมินนัดนี้**
2. ใส่รหัสแอดมิน กด **เข้าโหมดแอดมิน**

ส่งรหัสให้เพื่อนที่ไว้ใจ เพื่อนก็เป็นแอดมินได้

### ยืนยันวันนัด (แอดมิน)

1. ในกล่อง **ยืนยันวัน** กด **เลือกวันที่จะนัด**
2. แตะวันในปฏิทิน หรือพิมพ์ แล้วกด **ใส่**
   - ช่วงวัน: `10-13`
   - หลายวัน: `10,12,15`
   - ใช้วันของเดือนที่ปฏิทินแสดงอยู่
3. ดูสรุป
   - **มาได้ทุกวัน** — ใครบ้าง กี่คน
   - **ว่างบางวัน** — ใคร และไม่ว่างวันไหน
   - **ไม่ว่างเลย** — ใครบ้าง
4. กด **ยืนยันวันนี้** ทุกคนจะเห็นแถบสีเขียวด้านบนพร้อมวันที่นัด

เปลี่ยนใจ: กด **ยกเลิกการยืนยัน** (กด 2 ครั้ง)

### ลบชื่อคนที่ลง (แอดมิน)

ในรายการ **ใครลงแล้วบ้าง** กด **ลบ** ข้างชื่อ แล้วกด **ยืนยันลบ**

## คำถามที่พบบ่อย

**ต้องสมัครอะไรไหม**
ไม่ต้อง เปิดลิงก์แล้วใช้ได้เลย

**คนอื่นแก้วันของเราได้ไหม**
ไม่ได้ แต่ละคนแก้ได้เฉพาะของตัวเอง แอดมินลบชื่อได้อย่างเดียว

**ลืมรหัสแอดมิน**
กู้ไม่ได้ ให้สร้างนัดใหม่ หรือถามเพื่อนที่มีรหัส

**ลิงก์ภาษาไทยยาวมาก**
ใช้ได้ปกติ ถ้าอยากได้ลิงก์สั้น ตั้งชื่อนัดเป็นภาษาอังกฤษ เช่น `cnx-trip`

**เว็บไม่อัปเดต / หน้าตาแปลก**
กด Ctrl+F5 (คอม) หรือปิดแล้วเปิดแท็บใหม่ (มือถือ)
